# Russel Osiemo, personal site

Plain HTML and CSS, no build step. Deployed on Netlify from `main`.

- `index.html`: home and about
- `work.html`: case studies and earlier work
- `assets/css/site.css`: the only stylesheet
- `assets/fonts/`: Source Serif 4 and IBM Plex Sans (SIL Open Font Licence)

Preview locally with `python -m http.server 8000` and open http://localhost:8000.
